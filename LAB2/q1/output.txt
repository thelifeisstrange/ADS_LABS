=============================================== MATHEMATICAL ANALYSIS ===============================================
Total Operations (n)       : 14
Total Actual Cost (Sum C_i): 28
Average / Amortized Cost   : Total Cost / n = 28 / 14 = 2.0000 ~ O(1)

THEORETICAL PROOF WITH MULTIPOP:
1. Each element can be pushed at most once (Cost = 1).
2. Each element can be copied during resizing at most O(log n) times across geometric doublings (< 2n total copies).
3. Each element can be popped (via POP or MULTIPOP) at most once throughout the entire sequence.
   -> Total number of pops (single + multipop) <= Total number of pushes <= n.
4. Total sequence cost T(n) <= (Push Cost) + (Resize Cost) + (Total Pop/Multipop Cost)
                           <= n + 2n + n = 4n
5. Amortized Cost per operation = T(n) / n <= 4n / n = 4 = O(1)
